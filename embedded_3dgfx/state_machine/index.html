Zero-allocation application state machine inspired by bevy_state.

Embedded titles transition through high-level phases (e.g. Boot, TitleScreen, Gameplay, Pause, GameOver).

This module provides a deterministic, zero-heap state machine wrapper around any Copy + PartialEq enum. It exposes change detection (just_entered, just_exited) so systems can run one-shot enter/exit routines without global boolean flags.
