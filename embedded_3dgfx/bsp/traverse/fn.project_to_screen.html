Expand description

Project a clip-space vertex to integer screen coordinates.

Returns (screen_xy, depth, clip_w). depth is in the same scale as K3dengine::transform_point_with_w (maps NDC z to [near, far] float range, later converted to 16.16 by the rasterizer).

Returns None if the vertex has non-positive w (behind camera) or if NDC z is out of [-1, 1].
