Expand description

A mesh with optional Level of Detail (LOD) support

Fields§

§similarity: Similarity3<f32>§model_matrix: Matrix4<f32>§color: Rgb565§render_mode: RenderMode§geometry: Geometry<'a>§lod_medium: Option<Geometry<'a>>

Optional LOD geometries (medium detail, low detail) If None, only the main geometry is used

§lod_low: Option<Geometry<'a>>§lod_levels: LODLevels§priority: u8§outline_color: Option<Rgb565>§outline_width: f32§aabb: Option<Aabb>

Cached model-space AABB used for two-stage frustum culling / raycast. Call Self::cache_aabb after geometry changes (or at load time).

§layers: RenderLayers

Visibility layers. Default: layer 0 (intersects the default camera).

pub fn compute_bounding_radius_sq(&self) -> f32

Compute the squared bounding sphere radius of the mesh in world-ish scale (model-space radius × uniform scale²).

With aabb-cull, uses the cached AABB when present (tighter than origin-centered verts).
