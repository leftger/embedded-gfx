embedded_3dgfx::bsp

Module coverage 

Source
Expand description

Per-pixel coverage buffer for BSP front-to-back rendering (Milestone 5).

In front-to-back BSP traversal the first draw to any pixel is always the correct (nearest) surface. A 1-bit coverage bitmap then replaces the full 32-bit z-buffer, saving ~128 KB RAM at 240×135.

§Usage

ⓘ
const W: usize = 240;
const H: usize = 135;
let mut cov_data = [0u8; CoverageBuffer::bytes_for(W, H)];
let mut cov = CoverageBuffer::new(&mut cov_data, W, H).unwrap();

// each frame:
cov.clear();
engine.render_bsp_coverage(&world, &mut scratch, &texture_mgr, fb, &mut cov, tel);
