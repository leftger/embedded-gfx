pub fn build_room_strip(rooms: &[RoomSpec]) -> Result<OwnedBspWorld, BuildError>
Expand description

Build a simple BSP world from an X-sorted strip of axis-aligned rooms.

Generated geometry includes floor, ceiling, and side/end walls per room, full-visibility PVS, and an X-axis BSP split tree with root at node 0.
